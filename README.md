# Unex - Redesign de Landing Page

Projeto completo de Redesign da Landing Page Institucional da **Unex** (Centro Universitário), desenvolvido como atividade prática de Front-End e UX/UI.

## 🚀 Tecnologias Utilizadas
- **React 18** (Vite)
- **Tailwind CSS 3**
- **Lucide React** (Ícones)

## 📦 Como rodar o projeto localmente no VS Code

1. Extraia o conteúdo deste arquivo `.zip` na sua máquina.
2. Abra a pasta do projeto no **VS Code**.
3. Abra o terminal integrado (`Ctrl + '` ou `Cmd + '`) e execute:

```bash
# 1. Instalar todas as dependências
npm install

# 2. Iniciar o servidor de desenvolvimento
npm run dev
```

4. Acesse no navegador o endereço exibido no terminal (geralmente `http://localhost:5173`).

## 🌐 Publicação (Deploy)
Este projeto está pronto para ser publicado na **Vercel** ou **Netlify**:
1. Crie um repositório no GitHub/GitLab e envie estes arquivos.
2. Importe o repositório na Vercel/Netlify.
3. O build será detectado automaticamente (`npm run build`).
